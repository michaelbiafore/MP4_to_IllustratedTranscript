# Create new slash command /MP4+WizWhisp.


> These are instructions for you to create a new slash command that will "collate" a local MP4, as created by EaseUS RecExperts, for example, and a transcript as created by  WizWhisp for example.
>
> Sample the MP4 at 5s intervals unless a different interval is specified, taking screenshots. You do not need to process the audio, except possibly to align with the transcript. After you have collected all of the screenshots you will select out only the "interesting" ones to use as figures in the "formatted-transcript" (Markdown and HTML[portable]) and slide deck (HTML[portable]) you will be creating from the transcript. 
>
> A screenshot is "interesting" if it is not: (1) one or more human talking heads, people standing, body part (e.g. hands hovering over a screen that cannot be read), (2) a duplicate of a slide with an earlier timestamp (3) a "partial reveal" of a slide with a later timestamp, (4) a logo or an advertisement.
>
> Insert the "interesting" screenshots into the "formatted transcript" as nearly as possible at the point in time in which they occurred. 
>
> Unless given a specific number of slides to target, use as many as you need, given the number of "interesting" screenshots you find.
>
> Use _all_ of the interesting screenshots you find in both the formatted-transcript and the slides.
>
> Make all HTML output "portable" in the sense that the HTML deck alone can be sent by email and will display properly on a remote system where various libraries may be in a different place or absent altogether.
>
> Use the same style as in: A:\Packages\Transcript2MDSlides\Output\Formatted\Build_with_Claude_Code_Session_2_Agentic_Engineering_FORMATTED_TRANSCRIPT.html, that is "green div bars", "sans serif" fonts, a table of contents with links to later sections that you have tested and verified works.
